# Operia Lab

Vitrine estática de soluções digitais aplicadas da Operia Lab.

## Destaque atual

- Zelador.ia: landing, web demo, planos e acompanhamento de ordens de serviço por empreendimento.

## Publicação

Este pacote pode ser publicado via GitHub Pages a partir da raiz do repositório.

Observação: a análise visual real do Zelador.ia usa backend Python com `OPENAI_API_KEY`. Em GitHub Pages, a interface continua abrindo como landing/demo estática e usa fallback local quando a API não estiver disponível.
